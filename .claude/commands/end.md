จบ session การทำงานบน repo นี้

ใช้ skill `session-handoff` โหมด **END** และทำตามขั้นตอนในนั้นให้ครบ สรุปคือ:

1. ทบทวนว่ารอบนี้เกิดอะไรขึ้น — ไล่จาก `git status`, `git diff` และบทสนทนาที่ผ่านมา
2. ติ๊ก checkbox ในไฟล์แผน (`- [ ]` → `- [x]`) เฉพาะ step ที่ทำเสร็จจริงในรอบนี้
3. เขียน `docs/HANDOFF.md` **ทับของเก่า** (ไม่ต่อท้ายไปเรื่อยๆ) ตามโครงในสกิล: ทำอะไรไป / ค้างตรงไหน / blocker / ทำอะไรต่อ — เขียนให้จำเพาะพอที่อีกคนลงมือต่อได้ทันที
4. **ถ้ารอบนี้แตะไฟล์ใน `frontend/` ให้รัน `cd frontend && npm run build` ก่อน** — push เข้า main แล้ว Vercel deploy ขึ้น production ทันที ถ้า build ไม่ผ่านให้หยุดบอกผู้ใช้ อย่าไปต่อ
5. `git status` + `git diff --stat` — ดูว่ามีไฟล์ credential ปนมาไหม (`.env`, `.json` ที่หน้าตาเหมือน key, อะไรที่มีคำว่า key/secret/token) ถ้าเห็นให้หยุดถามก่อน
6. **แสดงให้ผู้ใช้ดูว่าจะ commit ไฟล์อะไรบ้าง พร้อมร่างข้อความ commit แล้วรอให้ยืนยันก่อน** — อย่า commit + push เอง เพราะ push = ขึ้น production ทันที เมื่อยืนยันแล้วค่อย `git add` → `git commit` → `git push`
7. สรุปให้ผู้ใช้ 2-3 บรรทัดว่า push อะไรขึ้นไป และอีกคนจะเห็นอะไรตอนเปิดมา — ถ้ารอบนี้มีการเปลี่ยน `frontend/` ให้บอกด้วยว่าเว็บจริงจะอัปเดตตามภายในไม่กี่นาที
