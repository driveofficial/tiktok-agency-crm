จบ session การทำงานบน repo นี้

ใช้ skill `session-handoff` โหมด **END** และทำตามขั้นตอนในนั้นให้ครบ สรุปคือ:

1. ทบทวนว่ารอบนี้เกิดอะไรขึ้น — ไล่จาก `git status`, `git diff` และบทสนทนาที่ผ่านมา
2. ติ๊ก checkbox ในไฟล์แผน (`- [ ]` → `- [x]`) เฉพาะ step ที่ทำเสร็จจริงในรอบนี้
3. เขียน `docs/HANDOFF.md` **ทับของเก่า** (ไม่ต่อท้ายไปเรื่อยๆ) ตามโครงในสกิล: ทำอะไรไป / ค้างตรงไหน / blocker / ทำอะไรต่อ — เขียนให้จำเพาะพอที่อีกคนลงมือต่อได้ทันที
4. ดู `git status` ว่ามีไฟล์ credential ปนมาไหม (`.env`, `.json` ที่หน้าตาเหมือน key, อะไรที่มีคำว่า key/secret/token) ถ้าเห็นให้หยุดถามก่อน
5. `git add` → `git commit` → `git push`
6. สรุปให้ผู้ใช้ 2-3 บรรทัดว่า push อะไรขึ้นไป และอีกคนจะเห็นอะไรตอนเปิดมา

ถ้าอยู่บน branch ของตัวเองและงานเสร็จพร้อม merge แล้ว ให้เสนอเปิด PR ด้วย `gh pr create` — แต่ถามก่อน อย่าเปิดเอง
