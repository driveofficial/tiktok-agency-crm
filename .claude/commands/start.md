---

เริ่ม session การทำงานบน repo นี้

ใช้ skill `session-handoff` โหมด **START** และทำตามขั้นตอนในนั้นให้ครบ สรุปคือ:

1. `git pull` แล้ว `git log --oneline -10` — ดูว่าอีกคนทำอะไรไปบ้าง
2. อ่าน `docs/HANDOFF.md` และไฟล์แผนใน `docs/superpowers/plans/` ที่ยังมี `- [ ]` ค้าง
3. สรุปให้ผู้ใช้เป็นภาษาไทยสั้นๆ 3 อย่าง:
   - มีอะไรเปลี่ยนตั้งแต่ครั้งที่แล้ว
   - ตอนนี้ค้างอยู่ตรงไหน / blocker คืออะไร
   - ทำอะไรต่อได้เลย (เสนอ 1-2 ทางเลือกที่ชัดเจน ไม่ต้องแจกแจงทุกความเป็นไปได้)

ถ้า `git pull` ติด conflict หรือมี working tree ที่ยังไม่ commit ให้หยุดแล้วถามผู้ใช้ก่อน อย่า resolve เองเงียบๆ

ถ้า `docs/HANDOFF.md` ไม่ตรงกับ `git log` ให้บอกตรงๆ ว่าไม่ตรง แล้วเชื่อ git log เป็นหลัก
